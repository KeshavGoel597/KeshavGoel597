* Achieved a **5.0x computational speedup (6.59 GFLOPS)** for heavy mathematical logic.
* Employed Linux profiling tools (`perf`, `gprof`) to aggressively isolate and resolve a severe 59% cache-miss memory bottleneck.

### Quantitative Trading Backtesting Engine
* Built a Python-based operational tool to monitor and backtest algorithmic trading strategies.
* Processed massive volumes of real-time financial tick data to simulate an ATM straddle strategy on NIFTY indices.
* Developed robust algorithms to generate comprehensive risk metrics and evaluate real-time strategy performance.

### High-Concurrency Distributed File System
* Architected a multi-threaded distributed storage system using rigorous POSIX socket programming in C.
* Managed high-throughput data requests from 100+ concurrent clients flawlessly.
* Engineered cache-efficient data structures implementing djb-2 hashing for O(1) memory lookups and fine-grained sentence-level mutex locking.

### OS Kernel Architecture & POSIX Shell
* Demonstrated deep Linux OS knowledge by modifying core xv6 kernel data structures, developing custom memory management (demand paging) and thread schedulers.
* Programmed a POSIX-compliant UNIX shell in C featuring n-length pipelines, background job control, and signal-safe real-time atomic operations.

### S.H.A.M. Reliable UDP Protocol
* Engineered a custom reliable transport protocol over UDP in C.
* Implemented precise connection management through 3-way handshakes and 4-way teardowns.
* Developed robust custom packet sequencing, retransmission logic, and a sliding window protocol to actively prevent buffer overflow.
